▸ ELECTRS — BLOCK EXPLORER
Electrs provides fast address lookups and transaction data via its HTTP REST API. Start9 users: Start9 Electrs only exposes the Electrum TCP protocol externally — use ESPLORA / MEMPOOL mode and point Falconer at your local Mempool service, which provides the same REST API. For self-hosted nodes that expose Electrs REST on port 3002, use LOCAL, REMOTE, or TOR mode.
◆ ESPLORA / MEMPOOL MODE — Falconer will prepend /api to all blockchain queries, making it compatible with any Mempool.space-style Esplora HTTP API.
Start9 users: Enter your local Mempool .onion address (find it at Start9 → Services → Mempool → Interfaces). Or use https://mempool.space for the public API.
default REST port: 3002
◆
Tor Hidden Service mode — for nodes that expose the Electrs HTTP REST API as a Tor hidden service on port 3002.
Start9 users: Start9's Electrs only exposes the Electrum TCP binary protocol over Tor (port 50001) — there is no REST API .onion. Use mode instead and point it at your local Start9 Mempool (Start9 → Services → Mempool → Interfaces).
The Tor daemon must be running on this machine (127.0.0.1:9050). Install: brew install tor && brew services start tor
Quick Connect (Electrum format — optional)
Format: host:port:protocol — t = Electrum TCP (port 50001) · s = Electrum SSL (port 50002). These are not HTTP REST ports — see warning below.
the full .onion hostname — no http:// prefix
⚠ HTTP REST port only — ports 50001 (Electrum TCP) and 50002 (Electrum SSL) use a binary wire protocol and will not work here.

Start9 users: Try the same .onion hostname with port 3002 — some Start9 setups route the REST API over the same Tor hidden service on a different port. If that fails, switch to REMOTE mode and use your node's LAN IP or .local hostname with port 3002.
